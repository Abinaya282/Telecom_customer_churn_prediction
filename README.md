# Telecom_customer_churn_prediction
Telecom Customer Churn Prediction – A Data Science project that analyzes customer data and builds machine learning models to predict customer churn and support customer retention strategies.

## 📌 Project Overview
This project predicts whether a telecom customer is likely to churn using Data Science & Machine Learning. The project includes data preprocessing, exploratory data analysis (EDA), visualization, feature engineering, and classification using Logistic Regression.

## 🎯 Objective
- Analyze customer behavior and service usage.
- Identify factors influencing customer churn.
- Build a machine learning model to predict customer churn.

## 📂 Dataset
- **Dataset:** Telecom Customer Churn Dataset
- **Target Variable:** Churn
- **Features:** Customer demographics, account information, internet service, contract details, billing information, and support services.
